# 🧩 Product Modules

## 1️⃣ Dinacharya Engine – Ayurvedic Lifestyle Intelligence

A personalized daily routine generator based on Prakriti:

* Vata
* Pitta
* Kapha
* Balanced

### Capabilities

* Full-day structured schedule (8–9 timestamps)
* Time-optimized meals & sleep cycles
* Yoga & meditation recommendations
* Dynamic rendering via EJS

### Architecture Flow

User Input → Dosha Mapping → Routine Model → Rendered Schedule

---

## 2️⃣ AI Yoga Posture Correction

A real-time computer vision system built using:

* Browser Webcam API
* MediaPipe Pose
* JavaScript landmark & angle analysis

### Capabilities

* Live pose detection
* 33 body landmark tracking
* Joint angle computation
* Correct / Incorrect posture detection
* On-screen visual feedback

### Technical Flow

Camera Stream → MediaPipe Pose → Landmark Extraction → Angle Calculation → Feedback Overlay

This reduces injury risk and improves yoga accuracy without needing a trainer.

---

## 3️⃣ Saarthi – AI Spiritual Companion

An emotional intelligence module inspired by Sanskrit wisdom.

User writes:

> “I feel anxious before exams.”

System:

* Finds a relevant shlok from Bhagavad Gita dataset
* Displays Sanskrit verse
* Provides simple explanation
* Delivers contextual motivation

### Why This Matters

We combine emotional expression with scriptural insight to create culturally rooted digital therapy support.
